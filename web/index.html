Build the offline game

For Android or iPhone/iPad, from your own files. Everything runs in this browser; your files are never uploaded.

[01 Platform]

[02 Your files]

GAME Original 3.7.1 ARM64 APK: Global (English/Korean) or Japanese (experimental). NOT CHOSEN
MASTER DATA The original master data: 20240404193219.bin.e for the Global APK, 20240405123139.bin.e for the Japanese APK. NOT CHOSEN

[03 Build]

Takes a few minutes and needs about 2 GB of free memory. A desktop browser works best.

EXPERIMENTAL :: PORT OFFSET

The game talks to its server on this device through ports 8003, 8080 and 3000. If another app already uses one of them, the launcher tells you. An offset moves all three. For example, 30000 gives 38003, 38080 and 33000. Leave it at 0 unless you need it, and use the same offset for updates.

[04 Install]

Download

The APK is signed and ready to install. Every APK built on this page is signed with the same public Bunker key, so a newer build installs over an older one and keeps your saves. Download the key (bunker-key.p12, password and alias bunker) to sign your own builds the same way. The key is public, so anyone's build can install over yours. To prevent this, sign with a key of your own instead.

The same APK runs on a Windows PC with an Intel or AMD processor, in Google's Android Emulator. Download Bunker.exe from the latest release and put it in one folder with the APK, named bunker.apk, and resource_dump_android.7z. Turn on Windows Hypervisor Platform in Windows features, then double-click Bunker.exe. The first start downloads about 2.3 GB from Google and copies the game files in. Open the launcher with Ctrl+B and move with WASD. See Play on Windows.

The IPA is unsigned. Install it with Sideloadly or AltStore and your Apple ID, or sign it with your own certificate. Use the same bundle ID for updates to keep your saves. The same IPA runs on a Mac with Apple silicon if your Apple developer team signs it for that Mac. Build it with a port offset (for example 30000), and open the launcher with ⌘B. See Play on a Mac.

Then copy the resource dump's .7z to the device and choose it in the Bunker. The app unpacks only the files the game uses. An extracted folder works too, as described in the guide. The Android build made here has no in-game Facebook account link. Offline play, Pod Programs and save backups work.
