Lunar Tear All-in-One

Build the offline game for Android or iPhone/iPad from your own files. Everything runs in this browser; your files are never uploaded.

1. Platform

2. Your files

The original 3.7.1 ARM64 game APK.

The original master data, 20240404193219.bin.e.

3. Build

Takes a few minutes and needs about 2 GB of free memory. A desktop browser works best.

4. Sign and install

Download

The APK is unsigned. Sign it, for example with apksigner sign --ks my.keystore game-Offline.apk or uber-apk-signer, then install it. Keep your key: updates must be signed with the same one.

The IPA is unsigned. Install it with Sideloadly or AltStore and your Apple ID, or sign it with your own certificate. Use the same bundle ID for updates to keep your saves.

Then copy the game files to the device and choose them in the app's launcher, as described in the guide. The Android build made here leaves out the in-game Facebook account link; offline play, Tools and save backups work.

Based on Lunar Tear and its pinned upstream tools. Source: github.com/veritr1x/lunar-tear-all-in-one.
