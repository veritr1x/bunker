Build the offline game

For Android or iPhone/iPad, from your own files. Everything runs in this browser; your files are never uploaded.

[01 Platform]

[02 Your files]

GAME The original 3.7.1 ARM64 game APK. NOT CHOSEN
MASTER DATA The original master data, 20240404193219.bin.e. NOT CHOSEN

[03 Build]

Takes a few minutes and needs about 2 GB of free memory. A desktop browser works best.

EXPERIMENTAL :: PORT OFFSET

The game talks to its server on this device through ports 8003, 8080 and 3000. If another app already uses one of them, the launcher says so. An offset moves all three, for example 30000 gives 38003, 38080 and 33000. Leave it at 0 unless you need it, and use the same offset for updates.

[04 Install]

Download

The APK is signed and ready to install. Every APK built on this page is signed with the same public Bunker key, so a newer build installs over an older one and keeps your saves. Download the key (bunker-key.p12, password and alias bunker) to sign your own builds the same way. The key is public: to keep anyone else's build from installing over yours, sign with a key of your own instead.

The IPA is unsigned. Install it with Sideloadly or AltStore and your Apple ID, or sign it with your own certificate. Use the same bundle ID for updates to keep your saves.

Then copy the resource dump's .7z to the device and choose it in the Bunker; the app unpacks only the files the game uses. An extracted folder works too, as described in the guide. The Android build made here leaves out the in-game Facebook account link; offline play, Pod Programs and save backups work.
